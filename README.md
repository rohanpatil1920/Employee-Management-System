# 🧑‍💼 Employee Management System (Java Desktop Application)

## 📌 Overview
The **Employee Management System** is a Java desktop application that allows organizations to manage all employee records in a centralized database. Users can **add, view, update, and delete** employee information efficiently through a simple and intuitive graphical user interface.

This project demonstrates **Core Java**, **Object-Oriented Programming (OOP)** concepts, and **database connectivity using JDBC**.

---

## ✨ Features
- Add new employee records  
- View existing employee details  
- Update employee information  
- Delete employee records when employees leave the company  
- Centralized data management through a relational database  
- User-friendly desktop GUI using **Java Swing & AWT**  

---

## 🛠️ Technologies & Concepts Used
- **Java** – Core Java and OOP principles  
- **Java Swing & AWT** – Desktop GUI development  
- **JDBC** – Database connectivity for CRUD operations  

**Object-Oriented Programming Concepts:**
- Constructors  
- Inheritance  
- Method Overriding  
- Encapsulation  
- Exception handling for robust application performance  

---

## 🗄️ Database Design
The system uses a relational database to store employee details, including:

- Employee ID  
- Name  
- Department / Role  
- Contact Information  
- Salary  

Database operations (**Create, Read, Update, Delete**) are handled using **JDBC**, ensuring secure and efficient communication between the application and the database.
